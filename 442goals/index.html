What this app is

442goals Uploader is a private, single-user tool operated by Markhabo Okhunova, the owner of the 442goals YouTube channel and the @442goals Instagram page. It uploads short football highlight videos produced by the channel owner to the channel owner's own YouTube channel. It is not offered to the public and no other person can sign in to it.

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • One OAuth scope only: youtube.upload — permission to upload videos to the authorized channel.
  • The app sends the video file, title, description and tags that the channel owner prepared.
  • It does not read, collect or store viewers' data, comments, subscribers, analytics or any other personal information.

Storage and sharing

The OAuth access token is stored only on the channel owner's own computer, in a local file excluded from version control. No data is sent to any server other than Google/YouTube, and nothing is sold or shared with third parties. The app uses no cookies and no analytics.

Revoking access and deletion

Access can be revoked at any time on the Google security settings page. Deleting the local token file removes all stored data. Videos already uploaded can be deleted in YouTube Studio.
